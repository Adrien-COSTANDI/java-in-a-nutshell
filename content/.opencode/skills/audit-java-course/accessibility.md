# Accessibilité pédagogique



## Principe



L'accessibilité du cours concerne principalement la capacité d'un apprenant à comprendre, naviguer et utiliser le contenu sans devoir deviner les informations implicites.



## Lisibilité



Vérifier :



* phrases excessivement longues ;

* paragraphes trop denses ;

* titres insuffisamment descriptifs ;

* listes utilisées lorsqu'elles améliorent la compréhension ;

* absence de structure ;

* vocabulaire inutilement complexe.



## Concepts techniques



Lorsqu'un terme technique apparaît pour la première fois :



* vérifier qu'il est défini ou contextualisé ;

* vérifier que son rôle est compréhensible ;

* éviter les acronymes non expliqués.



Exemple :



Mauvais :



> Utilisez DI avec IoC.



Préférable :



> L'injection de dépendances (DI) consiste à fournir à un objet les dépendances dont il a besoin au lieu de les créer lui-même.



## Code



Le code doit être :



* suffisamment court pour être compris ;

* correctement indenté ;

* cohérent avec les conventions utilisées dans le cours ;

* accompagné d'une explication lorsque son comportement n'est pas évident.



Éviter les exemples contenant simultanément trop de concepts nouveaux.



## Consignes



Une consigne d'exercice doit permettre de comprendre :



* ce qu'il faut produire ;

* quelles contraintes respecter ;

* ce qui doit être observé ;

* éventuellement comment vérifier le résultat.



Identifier les consignes qui supposent des connaissances non enseignées.



## Charge cognitive



Identifier les passages présentant simultanément trop de nouveaux concepts.



Exemple :



Une première introduction à une classe ne devrait pas nécessairement introduire en même temps :



* héritage ;

* génériques ;

* exceptions ;

* streams ;

* lambdas ;

* annotations.



Lorsque plusieurs concepts sont volontairement combinés, le cours doit expliquer pourquoi.



## Navigation



Un apprenant doit pouvoir répondre facilement aux questions :



* Où suis-je ?

* Qu'est-ce que je suis censé connaître avant cette section ?

* Que dois-je apprendre maintenant ?

* Que dois-je faire ensuite ?

* Où retrouver l'explication d'un concept précédent ?



## Accessibilité cognitive



Signaler :



* informations importantes noyées dans de longues notes ;

* absence de résumé ;

* absence d'objectifs pédagogiques ;

* changements brusques de niveau ;

* exemples sans contexte ;

* dépendance à des connaissances implicites.



Ne pas confondre accessibilité et simplification excessive.



Un contenu techniquement avancé peut rester accessible s'il est correctement introduit et structuré.
