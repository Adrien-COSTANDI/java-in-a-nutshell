### Exercice 4 : Devine le nombre

**Notions** : boucles (`while`), conditions, `Math.random()`

Le programme choisit un nombre aléatoire entre 1 et 100. L'utilisateur doit le deviner. À chaque tentative, le programme indique si c'est trop haut ou trop bas.

```java
void main() {
  int secret = (int) (Math.random() * 100) + 1;
  int guess;
  int attempts = 0;

  do {
    guess = Integer.parseInt(IO.readln("Devinez le nombre (1-100) : "));
    attempts++;

    if (guess < secret) {
      IO.println("Trop bas !");
    } else if (guess > secret) {
      IO.println("Trop haut !");
    } else {
      IO.println("Bravo ! Trouvé en " + attempts + " coups.");
    }
  } while (guess != secret);
}
```

### Exercice 7 : Références partagées

**Notions** : références, heap/stack

Sans exécuter le code, déterminez l'affichage :

```java
void main() {
  int[] a = {1, 2, 3};
  int[] b = a;
  b[0] = 99;
```

## equals et hashCode (chapitre 21)

### Exercice 8 : Classe Student

**Notions** : `equals()`, `hashCode()`

Créez une classe `Student` avec un `id` (int), un `name` (String). Deux étudiants sont égaux s'ils ont le même id. Implémentez `equals()` et `hashCode()`.


```java
import java.util.Objects;

public class Student {
  private int id;
  private String name;

  public Student(int id, String name) {
    this.id = id;
    this.name = name;
  }

  @Override
  public boolean equals(Object obj) {
    if (this == obj) return true;
    if (obj == null || getClass() != obj.getClass()) return false;
    Student other = (Student) obj;
    return id == other.id; // compare uniquement l'id
  }

  @Override
  public int hashCode() {
    return Objects.hash(id); // basé uniquement sur l'id
  }

  @Override
  public String toString() {
    return "Student #" + id + " (" + name + ")";
  }
}
```

## Héritage et interfaces (chapitres 18, 22-23)

### Exercice 9 : Formes géométriques

**Notions** : héritage, classes abstraites, polymorphisme

Créez une classe abstraite `Shape` avec une méthode abstraite `area()`. Créez les sous-classes `Circle`, `Rectangle`, `Triangle`. Créez un tableau de formes et affichez l'aire de chacune.


```java
public abstract class Shape {
  public abstract double area();

  @Override
  public String toString() {
    return getClass().getSimpleName() + " (aire: " + area() + ")";
  }
}

public class Circle extends Shape {
  private double radius;
  public Circle(double radius) { this.radius = radius; }
  @Override public double area() { return Math.PI * radius * radius; }
}

public class Rectangle extends Shape {
  private double width, height;
  public Rectangle(double width, double height) { this.width = width; this.height = height; }
  @Override public double area() { return width * height; }
}

public class Triangle extends Shape {
  private double base, height;
  public Triangle(double base, double height) { this.base = base; this.height = height; }
  @Override public double area() { return base * height / 2; }
}

void main() {
  Shape[] shapes = {
    new Circle(5),
    new Rectangle(4, 6),
    new Triangle(3, 8)
  };

  for (Shape s : shapes) {
    IO.println(s);
  }
}
```

## Exceptions (chapitre 20)

### Exercice 13 : Gestion de notes

**Notions** : exceptions personnalisées, try/catch

Créez une méthode `calculateAverage(int[] notes)` qui lève une exception si une note est négative ou supérieure à 20.

```java
public class InvalidGradeException extends RuntimeException {
  public InvalidGradeException(int grade) {
    super("Note invalide : " + grade + " (doit être entre 0 et 20)");
  }
}

double calculateAverage(int[] notes) {
  int sum = 0;
  for (int note : notes) {
    if (note < 0 || note > 20) {
      throw new InvalidGradeException(note);
    }
    sum += note;
  }
  return (double) sum / notes.length;
}

void main() {
  int[] notes = {15, 18, 7, -3, 12};
  try {
    double avg = calculateAverage(notes);
    IO.println("Moyenne : " + avg);
  } catch (InvalidGradeException e) {
    IO.println("Erreur : " + e.getMessage());
  }
}
```

## Programmation fonctionnelle et Streams (chapitres 31-32)

### Exercice 14 : Traitement d'une liste de personnes

**Notions** : lambdas, streams

Soit une liste de personnes (nom, âge). Utilisez les streams pour :
1. Filtrer les mineurs
2. Récupérer les noms des majeurs triés par âge
3. Calculer l'âge moyen
4. Grouper par tranche d'âge (mineur/majeur)

```java
record Person(String name, int age) { }

void main() {
  List<Person> people = List.of(
    new Person("Alice", 25),
    new Person("Bob", 17),
    new Person("Charlie", 30),
    new Person("David", 15),
    new Person("Eve", 22)
  );

  // 1. Mineurs
  List<Person> minors = people.stream()
    .filter(p -> p.age() < 18)
    .toList();
  IO.println("Mineurs : " + minors);

  // 2. Noms des majeurs triés
  List<String> adults = people.stream()
    .filter(p -> p.age() >= 18)
    .sorted(Comparator.comparingInt(Person::age))
    .map(Person::name)
    .toList();
  IO.println("Majeurs : " + adults);

  // 3. Âge moyen
  double avg = people.stream()
    .mapToInt(Person::age)
    .average()
    .orElse(0);
  IO.println("Âge moyen : " + avg);

  // 4. Groupement
  Map<Boolean, List<Person>> byMajority = people.stream()
    .collect(Collectors.partitioningBy(p -> p.age() >= 18));
  IO.println("Majeurs : " + byMajority.get(true));
  IO.println("Mineurs : " + byMajority.get(false));
}
```
